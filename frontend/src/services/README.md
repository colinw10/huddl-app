# Services Layer

Add API integration and service files here.

## Team Instructions

- Create service files for backend communication
- Each service should export functions that call backend APIs
- Use consistent error handling
- **DO NOT modify UI components when adding services**

## Example Files

```
services/
├── api.js          // Axios/fetch configuration
├── authService.js  // Login, signup, logout
├── userService.js  // Profile operations
├── postService.js  // CRUD for posts
└── mediaService.js // Upload/download media
```
