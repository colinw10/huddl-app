3. KEY INTEGRATION POINTS
================================================================================

API BASE URL: http://localhost:8000/api

AUTHENTICATION ENDPOINTS (/api/auth/):
┌─────────────────────────────┬────────────────────────────────────────┐
│ Endpoint                    │ Frontend Usage                         │
├─────────────────────────────┼────────────────────────────────────────┤
│ POST /api/auth/signup/      │ Signup.jsx → AuthContext               │
│ POST /api/auth/login/       │ Login.jsx → AuthContext                │
│ POST /api/auth/token/refresh│ apiClient.js interceptor (auto)        │
│ GET  /api/auth/me/          │ AuthContext on mount (get current user)│
└─────────────────────────────┴────────────────────────────────────────┘

POSTS ENDPOINTS (/api/posts/):
┌─────────────────────────────┬────────────────────────────────────────┐
│ Endpoint                    │ Frontend Usage                         │
├─────────────────────────────┼────────────────────────────────────────┤
│ GET  /api/posts/            │ PostsContext → Home, Profile           │
│ POST /api/posts/            │ ComposerModal → PostsContext.createPost│
│ GET  /api/posts/:id/        │ (Not currently used - could be detail) │
│ GET  /api/posts/:id/replies/│ TimelineRiverRow → fetch thread        │
│ PATCH /api/posts/:id/       │ Edit post → PostsContext.updatePost    │
│ DELETE /api/posts/:id/      │ DeleteConfirmModal → PostsContext      │
└─────────────────────────────┴────────────────────────────────────────┘

FRIENDS ENDPOINTS (/api/friends/):
┌──────────────────────────────────┬─────────────────────────────────────┐
│ Endpoint                         │ Frontend Usage                      │
├──────────────────────────────────┼─────────────────────────────────────┤
│ GET  /api/friends/               │ FriendsContext → Friends.jsx        │
│ GET  /api/friends/requests/      │ FriendsContext → pending requests   │
│ POST /api/friends/request/:uid/  │ Friends.jsx → send request          │
│ POST /api/friends/accept/:rid/   │ Friends.jsx → accept request        │
│ POST /api/friends/decline/:rid/  │ Friends.jsx → decline request       │
│ DELETE /api/friends/remove/:uid/ │ Friends.jsx → unfriend              │
└──────────────────────────────────┴─────────────────────────────────────┘

6. POST TYPES (Important Constant)
================================================================================

The app has 3 post types:
- 'thought'   - Text-only posts (left column)
- 'media'     - Posts with images (center column)  
- 'milestone' - Achievement posts (right column)

These are stored in Post.type field and used for column layout in TimelineRiver.

7. KEY ARCHITECTURE PATTERNS
================================================================================

CONTEXT PATTERN:
- Each feature has a Context (AuthContext, PostsContext, etc.)
- Context provides state + actions to components
- Services handle actual API calls
- Components consume context via custom hooks (useAuth, usePosts, etc.)

SCSS ARCHITECTURE:
- Global styles in src/styles/
- Component styles co-located with components
- Partials prefixed with underscore (_base.scss)
- Modular imports via @use

ROUTING:
- React Router v6
- ProtectedRoute wraps authenticated pages
- Layout conditional based on route (no nav on landing/auth pages)
